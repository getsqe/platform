# chameleon_attachable_catalogs (Data Source)

List catalog names that can be attached to a workspace (all catalogs minus the workspace's own and already-attached ones). Requires a platform-admin identity.

## Example Usage

```terraform
# Discover which catalogs can be attached read-only to a workspace
# (all catalogs minus the workspace's own and already-attached ones).
data "chameleon_attachable_catalogs" "for_team_a" {
  workspace_slug = "team-a"
}

output "attachable" {
  value = data.chameleon_attachable_catalogs.for_team_a.catalogs
}
```
