# chameleon_dbt_session (Resource)

Opens a dbt session workspace for a project, cloning its git repo (POST /dbt/projects/{id}/sessions); closes it on destroy (DELETE /dbt/sessions/{id}). This makes the repo checkout Terraform-managed and provides the `session_id` that `chameleon_dbt_run` and a `chameleon_schedule` with `job_type = "dbt"` target. Changing `project_id` replaces the session. Read refreshes status from GET /dbt/sessions/{id}; a session closed out-of-band (404) is removed from state and recreated on next apply.

## Example Usage

```terraform
# A dbt session is an ephemeral git checkout (workspace) for a project. Opening
# it clones the repo; closing it (on destroy) cleans the workspace up. The
# session id is what chameleon_dbt_run and a dbt chameleon_schedule target.

resource "chameleon_dbt_session" "this" {
  project_id = chameleon_project.this.id
  # Workspace-scoped: the provider sends the X-Workspace header the BFF requires.
  workspace_slug = chameleon_workspace.team_a.slug
}

# Trigger a run against the freshly-cloned workspace. `command` selects the dbt
# verb (run | seed | test | compile). The run blocks until it finishes, so a
# failed run fails the apply and seed-then-run can be sequenced with depends_on
# in a single apply.
resource "chameleon_dbt_run" "build" {
  session_id     = chameleon_dbt_session.this.id
  workspace_slug = chameleon_workspace.team_a.slug
  command        = "run"
}
```
