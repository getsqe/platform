# chameleon_ontology_namespace (Resource)

An RDF prefix → URI binding registered with the Chameleon ontology (e.g. `schema` → `https://schema.org/`). Used by `chameleon_ontology_entity_type` and related resources to qualify IRIs.

**Caveat:** the BFF does not expose a DELETE endpoint for namespaces. `terraform destroy` removes the binding from state with a `Warning` diagnostic, but the namespace remains in the upstream ontology. Reapplying the same prefix + uri will idempotently re-register against the existing row.

## Example Usage

```terraform
# RDF prefix → URI binding registered with the Chameleon ontology.
# The BFF has no DELETE endpoint for namespaces — `terraform destroy`
# removes the resource from state with a warning but leaves the
# binding in the upstream ontology. Re-apply to rebind idempotently.
resource "chameleon_ontology_namespace" "schema_org" {
  prefix      = "schema"
  uri         = "https://schema.org/"
  description = "Schema.org vocabulary for general-purpose modeling"
}
```
