# chameleon_grant (Data Source)

Look up a single GRANT record. Provide either `id` or the full tuple (`privilege` + `catalog` + `grantee_type` + `grantee_name`, plus `namespace`/`table` if the grant is scoped below the catalog).

## Example Usage

```terraform
# Look up an existing GRANT by its tuple. Provide the same fields you would
# put on the resource (everything except `effect`); the data source returns
# the persisted record including its server-assigned id.
data "chameleon_grant" "by_tuple" {
  privilege    = "SELECT"
  catalog      = "main_warehouse"
  namespace    = "analytics"
  table        = "*"
  grantee_type = "GROUP"
  grantee_name = "SG-DataAnalysts"
}

output "grant_id" {
  value = data.chameleon_grant.by_tuple.id
}
```

## Schema

### Optional

- `catalog` (String) Warehouse name.
- `grantee_name` (String) Group or username this grant applies to.
- `grantee_type` (String) `GROUP` or `USER`.
- `id` (String) Grant UUID. Provide `id` OR the full tuple — not both.
- `namespace` (String) Namespace path (omit for catalog-level grants).
- `privilege` (String) SQL-style privilege (`USE`, `SELECT`, `MODIFY`, `CREATE`, `DROP`, `MANAGE`, `ALL`).
- `table` (String) Table name (omit for namespace-level grants).

- `granted_at` (String) RFC3339 timestamp of when the grant was issued.
- `granted_by` (String) Username of the principal who issued the GRANT.
- `resource_key` (String) Dot-joined fully-qualified resource (`catalog.namespace.table`).
- `resource_type` (String) Derived: `CATALOG`, `NAMESPACE`, or `TABLE`.
