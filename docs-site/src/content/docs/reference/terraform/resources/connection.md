# chameleon_connection (Resource)

A Git source connection used by `chameleon_dbt_project`. `type` must be one of `github`, `gitlab`, `bitbucket`, `generic_git`, `github_app`. The BFF returns the masked form `****` for credentials on read; the provider preserves the user-configured value in state so plan-vs-actual comparisons stay clean.

## Example Usage

```terraform
# A GitHub PAT-backed connection used by chameleon_project.
# Credentials are write-only; the BFF returns the masked form "****" on read,
# and the provider keeps the configured value in state to avoid synthetic drift.
resource "chameleon_workspace" "team_a" {
  slug         = "team-a"
  display_name = "Team A"
}

resource "chameleon_connection" "analytics" {
  name        = "analytics-github"
  type        = "github" # github | gitlab | bitbucket | generic_git | github_app
  url         = "https://github.com/example/analytics"
  credentials = var.github_pat # store outside source control
  # Scopes the connection to the workspace's members group (ws-team-a-members)
  # so workspace members can use it for dbt.
  workspace_slug = chameleon_workspace.team_a.slug
}
```

## Schema

### Required

- `credentials` (String, Sensitive) Provider-specific credentials (e.g. a Git PAT). Write-only; the BFF masks this on read. An empty/omitted value (e.g. when TF_VAR_dbt_git_credentials is unset) keeps the existing secret — it does NOT clear or replace the connection. A genuinely different non-empty value forces replacement (no PATCH upstream).
- `name` (String) Connection display name (unique within the team).
- `type` (String) Connection type: `github`, `gitlab`, `bitbucket`, `generic_git`, or `github_app`.
- `url` (String) Repository or host URL.
- `workspace_slug` (String) Slug of the workspace that owns this connection. Sent as the `X-Workspace` header, which scopes the connection so workspace members can use it for dbt. Pass `chameleon_workspace.<x>.slug` to order creation after the workspace.
