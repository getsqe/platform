# chameleon_dbt_lineage (Data Source)

Reads the lineage graph emitted by a single dbt run session from the BFF's `/dbt/sessions/{session_id}/lineage` endpoint. Shape mirrors `chameleon_table_lineage` — bipartite nodes/edges with run-level evidence counts. Use `chameleon_dbt_project` to identify the project, then point this data source at a session id from your run history.

## Example Usage

```terraform
# Read the lineage graph emitted by a single dbt run session.
# Pair with `chameleon_project` to discover the project, then look
# up a recent session id from your run history to feed in here.
data "chameleon_dbt_lineage" "last_run" {
  session_id = "2c8c1ef0-3f4e-4d1d-9b87-1c2a7e0a9f01"
}

output "produced_jobs" {
  value = [
    for n in data.chameleon_dbt_lineage.last_run.nodes : n.name
    if n.kind == "job"
  ]
}
```
