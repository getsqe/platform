# chameleon_project (Resource)

Manages a workspace project in the Chameleon platform. A project is a typed, git-backed directory tree of `kind` `dbt` or `notebook`. `kind=dbt` projects are created on the dbt projects endpoint (so they back `chameleon_dbt_session`/`chameleon_dbt_run`); `kind=notebook` projects are created on the shared workspace-projects endpoint. Replace-only: changing any input recreates the project.

## Example Usage

```terraform
resource "chameleon_workspace" "team_a" {
  slug         = "team-a"
  display_name = "Team A"
}

resource "chameleon_connection" "analytics" {
  name           = "analytics-github"
  type           = "github"
  url            = "https://github.com/example/analytics-dbt"
  credentials    = var.github_pat # store outside source control
  workspace_slug = chameleon_workspace.team_a.slug
}

# A dbt project. kind="dbt" routes to the dbt projects endpoint, so this project
# id can back chameleon_dbt_session / chameleon_dbt_run. connection_id + repo_url
# are required; workspace + warehouse are server-derived (read-only).
resource "chameleon_project" "analytics_dbt" {
  kind           = "dbt"
  name           = "analytics-dbt"
  workspace_slug = chameleon_workspace.team_a.slug
  connection_id  = chameleon_connection.analytics.id
  repo_url       = "https://github.com/example/analytics-dbt"
  repo_path      = "dbt"
  namespace      = "transformed"
}

# A notebook project. kind="notebook" routes to the shared workspace-projects
# endpoint. dbt-only fields (repo_url, repo_path, namespace, default_branch) are
# rejected; connection_id is optional (git-backed notebook).
resource "chameleon_project" "exploration" {
  kind           = "notebook"
  name           = "exploration"
  workspace_slug = chameleon_workspace.team_a.slug
  visibility     = "shared" # or "personal" (owned by the provider's principal)
  connection_id  = chameleon_connection.analytics.id
}
```

## Schema

### Required

- `kind` (String) Project kind: `dbt` or `notebook`.
- `name` (String) Project name (unique within the workspace).
- `workspace_slug` (String) Slug of the workspace that owns this project. Sent as the `X-Workspace` header (and the URL path for notebook projects). Pass `chameleon_workspace.<x>.slug` to order creation after the workspace.

### Optional

- `connection_id` (String) Git connection id (`chameleon_connection.<x>.id`). Required for `kind=dbt`; optional for notebooks.
- `default_branch` (String) Default git branch (`kind=dbt` only; notebooks are read-only `main` for now). Defaults to `main`.
- `namespace` (String) Default namespace within the warehouse where dbt outputs land (`kind=dbt` only).
- `repo_path` (String) Path within the repository where the dbt project lives (`kind=dbt` only). The provider preserves the configured value; the BFF's on-disk path is not surfaced.
- `repo_url` (String) Git repository URL. Required for `kind=dbt`; not used for notebooks.
- `visibility` (String) Project visibility: `shared` (workspace-wide) or `personal` (owned by the provider's principal). Defaults to `shared`. dbt projects are always `shared`.

### Read-Only

- `created_at` (String) RFC3339 creation timestamp.
- `created_by` (String) Username that created the project.
- `id` (String) Project UUID assigned by the BFF.
- `updated_at` (String) RFC3339 last-updated timestamp.
- `warehouse` (String) Warehouse the dbt project targets (server-derived; null for notebooks).
- `workspace` (String) Workspace the project belongs to (server-derived).
