# chameleon_table (Resource)

An empty Iceberg table inside a `chameleon_namespace`. Columns must use Iceberg primitive types — `int`, `long`, `string`, `boolean`, `float`, `double`, `date`, `timestamp`, `timestamptz`. Struct / map / list / decimal aren't supported via this resource; for those, use dbt or a one-shot Trino script. Every attribute except `metadata_location` forces replacement on change (the BFF / Polaris don't expose schema evolution through this endpoint).

## Example Usage

```terraform
# Iceberg table inside a namespace. Primitive columns only — use dbt or
# a one-shot script for struct/map/list/decimal types.
#
# Workspace-scoped: pass `workspace_slug` instead of `catalog` to create the
# table in the workspace's own catalog (ws_<slug>) — pass exactly one of
# `catalog` or `workspace_slug`.
resource "chameleon_table" "user_summary" {
  catalog   = chameleon_warehouse.analytics.name
  namespace = chameleon_namespace.reporting.name
  name      = "user_summary"

  columns = [
    { name = "id", type = "long", required = true },
    { name = "email", type = "string", required = true },
    { name = "signup_at", type = "timestamptz", required = true },
    { name = "total_spend", type = "double", required = false },
  ]

  # Optional: Iceberg table properties
  properties = {
    "format-version"               = "2"
    "write.target-file-size-bytes" = "134217728"
  }
}
```

## Schema

### Required

- `columns` (Attributes List) Ordered list of columns. Field ids are assigned 1-indexed in declaration order by the BFF — preserving the order lets the resulting Iceberg metadata be deterministic across clients. (see [below for nested schema](#nestedatt--columns))
- `name` (String) Table name.
- `namespace` (String) Namespace path within the catalog (dot-separated for nested).

### Optional

- `catalog` (String) Polaris catalog (warehouse) name. Mutually exclusive with `workspace_slug` — set exactly one.
- `location` (String) Optional override for the table's base location in S3. Leave unset to let Polaris pick a path under the catalog's default base location.
- `properties` (Map of String) Iceberg table properties (e.g. `format-version`, `write.target-file-size-bytes`).
- `workspace_slug` (String) Slug of a workspace to target instead of `catalog`; resolves to the workspace's primary catalog (`ws_<slug>` with hyphens as underscores). Mutually exclusive with `catalog` — set exactly one.

### Read-Only

- `id` (String) Composite id `<catalog>/<namespace>/<name>`. Used as the Terraform resource ID and for import.
- `metadata_location` (String) Pointer to the current Iceberg metadata JSON in S3. Updates on every schema commit, but this resource doesn't drive evolution — value is informational.
