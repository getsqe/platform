# chameleon_dbt_run (Resource)

Triggers a dbt command and waits for it to finish. Prefer the queue-backed project path by setting `project_id` (POST /dbt/projects/{id}/{command}); set `session_id` instead to use the legacy session path (POST /dbt/sessions/{id}/{command}). Exactly one of `project_id`/`session_id` must be set. One-shot: every input forces replacement. After triggering, the provider polls GET /dbt/runs/{id} until the run is terminal (success/failed/cancelled) or the apply deadline is hit; a `failed`/`cancelled` run fails the apply. Because the run blocks to completion, ordering (e.g. seed before run) can be expressed with `depends_on` within a single apply.

## Example Usage

```terraform
# Trigger a dbt build (the default command) via the preferred, queue-backed
# project path. The provider triggers the run, then polls until it reaches a
# terminal status (success/failed/cancelled); a failed/cancelled run fails the
# apply. Because the run blocks to completion, ordering can be expressed with
# depends_on within a single apply.
resource "chameleon_dbt_run" "build" {
  project_id     = chameleon_project.analytics_dbt.id
  workspace_slug = chameleon_workspace.team_a.slug
  models         = ["stg_orders", "fct_orders"]
  full_refresh   = true

  # Seeds first, in the same apply — the run waits, so depends_on now sequences
  # actual completion, not just the trigger.
  depends_on = [chameleon_dbt_run.seed]
}

# Other commands: "seed", "test", "compile". Set `command` to select the verb.
resource "chameleon_dbt_run" "seed" {
  project_id     = chameleon_project.analytics_dbt.id
  workspace_slug = chameleon_workspace.team_a.slug
  command        = "seed"
}

# The legacy session path is still supported: set `session_id` instead of
# `project_id` (exactly one of the two is required).
resource "chameleon_dbt_run" "build_on_session" {
  session_id     = chameleon_dbt_session.dev.id
  workspace_slug = chameleon_workspace.team_a.slug
  command        = "run"
}
```

## Schema

### Required

- `workspace_slug` (String) Slug of the workspace that owns the project/session. Sent as the `X-Workspace` header, which the BFF requires for workspace-scoped dbt operations; must match the project/session's workspace.

### Optional

- `command` (String) dbt command to trigger: `run`, `seed`, `test`, or `compile`. Defaults to `run`. Changing it triggers a new run. The BFF echoes the same verb back.
- `full_refresh` (Boolean) Pass --full-refresh. Applies to `run` only (`seed` always full-refreshes server-side; ignored for `test`/`compile`). Defaults to false.
- `models` (List of String) Optional model selector list. Omit to select all. Applies to `run` and `test`; ignored for `seed`/`compile`.
- `project_id` (String) dbt project to run via the queue-backed path. Mutually exclusive with `session_id`; exactly one must be set.
- `session_id` (String) dbt session workspace to run via the legacy path. Mutually exclusive with `project_id`; exactly one must be set.

### Read-Only

- `id` (String) Equals run_id.
- `log_output` (String) dbt log output captured for the run. Refreshed on read.
- `run_id` (String) BFF-assigned run id.
- `status` (String) Terminal run status (success, failed, or cancelled). Refreshed on read.
