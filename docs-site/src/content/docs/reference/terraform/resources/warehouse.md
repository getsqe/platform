# chameleon_warehouse (Resource)

Manages a Chameleon warehouse (Polaris catalog with S3 storage).

## Example Usage

```terraform
resource "chameleon_warehouse" "this" {
  name        = "analytics"
  description = "Primary analytics warehouse"
}

# Multi-warehouse setups: pin storage_config so Polaris doesn't reject the
# create with a "locations overlap with existing catalog" error. Anything
# left unset falls back to the BFF env defaults.
resource "chameleon_warehouse" "tenant_a" {
  name        = "tenant_a"
  description = "Per-tenant warehouse"

  storage_config = {
    default_base_location = "s3://my-bucket/tenant_a/"
    allowed_locations     = ["s3://my-bucket/tenant_a/"]
    path_style_access     = true # MinIO / rustfs / dev
  }
}
```

### Nested Schema for `storage_config`

Optional:

- `allowed_locations` (List of String) Locations Polaris is allowed to write under. Defaults (BFF-side) to the bucket root of `default_base_location`, which overlaps when warehouses share a bucket — set explicit scoped paths.
- `default_base_location` (String) Polaris default-base-location (e.g. `s3://my-bucket/my-warehouse/`). Scope this per warehouse when sharing a bucket.
- `path_style_access` (Boolean) True for MinIO/rustfs and other path-style S3 implementations. Leave unset to use the env default (typically `true` in the dev quickstart).
