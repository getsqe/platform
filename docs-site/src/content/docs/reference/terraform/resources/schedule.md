# chameleon_schedule (Resource)

Manages a unified job scheduler entry (dbt, langflow, dq, iceberg).

## Example Usage

```terraform
resource "chameleon_project" "analytics_dbt" {
  kind           = "dbt"
  name           = "analytics-dbt"
  workspace_slug = "team-a"
  connection_id  = chameleon_connection.analytics.id
  repo_url       = "https://github.com/example/analytics-dbt"
}

# Daily dbt build at 06:00 UTC, notifying Slack on failure.
resource "chameleon_schedule" "daily_build" {
  name            = "analytics-daily-build"
  description     = "Run dbt build for the analytics project every morning"
  job_type        = "dbt"
  target_id       = chameleon_project.analytics_dbt.id
  cron_expression = "0 6 * * *"
  timezone        = "UTC"
  enabled         = true

  target_config = {
    command = "dbt build --target prod"
  }

  notify_targets = ["slack://hooks.slack.com/services/T000/B000/XXX"]
  notify_on      = "failure"
}
```

## Schema

### Required

- `cron_expression` (String) Cron expression validated by croniter (5- or 6-field).
- `job_type` (String) Job kind: 'langflow', 'dbt', 'dq', or 'iceberg'. Changing replaces the schedule.
- `name` (String) Human-readable schedule name (1-200 chars).
- `target_id` (String) Opaque reference to the job target (e.g. dbt project id, langflow flow id). Changing replaces the schedule.

### Optional

- `description` (String) Optional description (max 1000 chars).
- `enabled` (Boolean) Whether the schedule fires (default true).
- `notify_on` (String) When to notify: 'always', 'failure', or 'success' (default 'failure').
- `notify_targets` (List of String) Apprise notification target URLs. The server redacts secrets in Read responses (e.g. 'slack://[redacted]'); supply full URLs when changing values. The provider preserves the configured plan/state value rather than overwriting state with the redacted form.
- `target_config` (Map of String) Job-type-specific parameters as a map(string). Encode complex values as JSON strings; the provider sends/receives them via the BFF as a generic map<string,any>, with non-string values JSON-encoded on read.
- `timezone` (String) IANA timezone name (default 'UTC').
