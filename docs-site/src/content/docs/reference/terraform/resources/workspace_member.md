# chameleon_workspace_member (Resource)

Adds a user to a workspace's members group (ws-<slug>-members). Requires a workspace-admin or platform-admin identity.

## Example Usage

```terraform
resource "chameleon_workspace" "team_a" {
  slug         = "team-a"
  display_name = "Team A"
}

# Add a user to the workspace's members group (ws-team-a-members). The user
# must already exist in Keycloak.
resource "chameleon_workspace_member" "alice" {
  workspace_slug = chameleon_workspace.team_a.slug
  username       = "alice"
}
```
