# chameleon_project (Data Source)

Look up a workspace project by name. The lookup spans both `dbt` and `notebook` kinds; set `kind` to disambiguate when names collide across kinds.

## Example Usage

```terraform
# Look up a workspace project by name. Set kind to disambiguate if a notebook
# and a dbt project share a name.
data "chameleon_project" "analytics_dbt" {
  name           = "analytics-dbt"
  workspace_slug = "team-a"
  kind           = "dbt"
}

output "analytics_dbt_id" {
  value = data.chameleon_project.analytics_dbt.id
}
```
