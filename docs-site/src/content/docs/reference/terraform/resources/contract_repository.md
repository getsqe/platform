# chameleon_contract_repository (Resource)

Registers a git repository the platform scans for ODCS contracts. Pair it with a `chameleon_connection` (which holds the git credentials). The BFF has no update endpoint, so changing any attribute replaces the repository. Use a `chameleon_schedule` (job_type "dq") or `auto_sync`/`sync_cron` to keep it synced.

## Example Usage

```terraform
# Registers a git repo the platform scans for ODCS contracts. It reuses a
# chameleon_connection for git credentials. Changing any attribute replaces the
# repository (the BFF has no update endpoint).

resource "chameleon_workspace" "team_a" {
  slug         = "team-a"
  display_name = "Team A"
}

resource "chameleon_connection" "contracts_git" {
  name           = "contracts-git"
  type           = "github"
  url            = "https://github.com/your-org/data-contracts"
  credentials    = var.git_token
  workspace_slug = chameleon_workspace.team_a.slug
}

resource "chameleon_contract_repository" "this" {
  connection_id = chameleon_connection.contracts_git.id
  path_filter   = "/contracts"
  branch        = "main"
  auto_sync     = true
  sync_cron     = "0 */6 * * *"
}

variable "git_token" {
  type      = string
  sensitive = true
}
```

## Schema

### Required

- `connection_id` (String) ID of the `chameleon_connection` holding git credentials. Changing replaces the repository.

### Optional

- `auto_sync` (Boolean) Whether the platform auto-syncs the repo on a schedule. Defaults to false.
- `branch` (String) Branch to scan. Defaults to 'main'.
- `path_filter` (String) Subpath within the repo to scan for contracts. Defaults to '/'.
- `sync_cron` (String) Cron expression for auto-sync (when auto_sync is true).

### Read-Only

- `created_at` (String) RFC3339 creation timestamp.
- `id` (String) Repository UUID assigned by the BFF.
