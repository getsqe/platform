# chameleon_keycloak_role (Resource)

Manages a Keycloak realm role (the identity-layer role, distinct from a `chameleon_principal_role`). The BFF exposes create/list/delete only — there is no update endpoint, so changing name or description replaces the role.

## Example Usage

```terraform
# A Keycloak realm role. These are identity-layer roles; reference the name from
# a chameleon_principal_role / policy subject to grant platform permissions.

resource "chameleon_keycloak_role" "data_analyst" {
  name        = "data-analyst"
  description = "Read-only access to analytics datasets"
}
```
