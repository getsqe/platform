# chameleon_ontology_mapping (Resource)

Binds an ontology element (entity / attribute / relation) to a physical Iceberg resource. Shape depends on `target_type`:

- `entity` — set `catalog` + `schema_name` + `table_name` (and optionally `filter_sql`).
- `attribute` — set `column_name`. `catalog` / `schema_name` / `table_name` are inherited from the parent entity's mapping at publish time.
- `relation` — set `join_sql` with `{source}` and `{target}` placeholders.

The endpoint upserts on `(version_id, target_type, target_id)`. The id Terraform stores is composite: `<version_id>/<target_type>/<target_id>`.

## Example Usage

```terraform
# Entity mapping — binds the abstract class to a physical Iceberg table.
resource "chameleon_ontology_mapping" "customer_table" {
  version_id  = chameleon_ontology_version.v1.id
  target_type = "entity"
  target_id   = chameleon_ontology_entity_type.customer.id
  catalog     = "main_warehouse"
  schema_name = "analytics_db"
  table_name  = "customers"
}

# Attribute mapping — only column_name; catalog/schema/table inherit from entity.
resource "chameleon_ontology_mapping" "customer_email_col" {
  version_id  = chameleon_ontology_version.v1.id
  target_type = "attribute"
  target_id   = chameleon_ontology_attribute.customer_email.id
  column_name = "email_addr" # physical column may differ from ontology name
}

# Relation mapping — join SQL with {source}/{target} placeholders.
resource "chameleon_ontology_mapping" "placed_by_join" {
  version_id  = chameleon_ontology_version.v1.id
  target_type = "relation"
  target_id   = chameleon_ontology_relation.placed_by.id
  join_sql    = "{source}.customer_id = {target}.customer_id"
}
```

## Schema

### Required

- `target_id` (String) UUID of the entity / attribute / relation being mapped.
- `target_type` (String) `entity` / `attribute` / `relation`.
- `version_id` (String) Ontology version (must be a draft for writes).

### Optional

- `catalog` (String) Polaris catalog. Required for `entity` mappings.
- `column_name` (String) Iceberg column. Required for `attribute` mappings.
- `filter_sql` (String) Optional WHERE-clause expression layered on top of the entity mapping.
- `is_active` (Boolean) Disable a mapping without deleting it. Default true.
- `join_sql` (String) SQL with `{source}` / `{target}` placeholders. Required for `relation` mappings.
- `schema_name` (String) Iceberg namespace. Required for `entity` mappings.
- `table_name` (String) Iceberg table. Required for `entity` mappings.

### Read-Only

- `id` (String) Composite id `<version_id>/<target_type>/<target_id>`.
- `lock_version` (Number) Optimistic-concurrency token.
- `status` (String) BFF-derived health: assigned / missing_columns / broken / unknown.
