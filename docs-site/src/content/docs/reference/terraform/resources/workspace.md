# chameleon_workspace (Resource)

Manages a Chameleon workspace (an isolated tenant: primary catalog, warehouse/staging buckets, and admin/member Keycloak groups). Backed by the idempotent PUT /workspaces/{slug} API; the provider identity must be a platform admin.

## Example Usage

```terraform
# A workspace is an isolated tenant: the platform provisions its primary
# catalog, warehouse/staging buckets, and admin/member Keycloak groups. The
# provider identity must be a platform admin.
resource "chameleon_workspace" "team_a" {
  slug         = "team-a"
  display_name = "Team A"
  description  = "Analytics workspace for Team A"
}

output "team_a_catalog" {
  value = chameleon_workspace.team_a.primary_catalog
}
```
