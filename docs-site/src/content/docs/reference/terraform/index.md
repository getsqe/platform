# chameleon Provider

Interact with the Chameleon data platform.

## Example Usage

```terraform
terraform {
  required_providers {
    chameleon = {
      source  = "registry.terraform.io/schubergphilis/chameleon"
      version = "~> 0.1"
    }
  }
}

variable "chameleon_client_id" {
  type      = string
  sensitive = true
}

variable "chameleon_client_secret" {
  type      = string
  sensitive = true
}

# Option 1: client credentials (recommended for service accounts)
provider "chameleon" {
  endpoint      = "https://chameleon.example.com"
  oidc_endpoint = "https://keycloak.example.com"
  client_id     = var.chameleon_client_id
  client_secret = var.chameleon_client_secret
}

# Option 2: static bearer token
# provider "chameleon" {
#   endpoint = "https://chameleon.example.com"
#   token    = var.chameleon_token
# }

# Option 3: ROPC (username/password) - useful for local dev only

#   oidc_endpoint = "http://platform.example"
#   username      = var.chameleon_username
#   password      = var.chameleon_password

# }
```

## Schema

### Optional

- `api_prefix` (String) API URL prefix on the BFF. Defaults to '/api/platform/v1'. May also be set via CHAMELEON_API_PREFIX.
- `ca_cert_path` (String) Path to a PEM-encoded CA certificate file to add to the trust pool. Useful for self-signed certs in dev environments. May also be set via CHAMELEON_CA_CERT_PATH.
- `client_id` (String, Sensitive) OAuth2 client ID (client_credentials and ROPC auth). Defaults to 'polaris-frontend-client' which matches the BFF's default audience. May also be set via CHAMELEON_CLIENT_ID.
- `client_secret` (String, Sensitive) OAuth2 client secret (client_credentials auth). May also be set via CHAMELEON_CLIENT_SECRET.
- `endpoint` (String) Chameleon BFF API base URL. May also be set via CHAMELEON_ENDPOINT.
- `oidc_endpoint` (String) Keycloak base URL for token acquisition. Required for client_credentials and ropc auth. May also be set via CHAMELEON_OIDC_ENDPOINT.
- `password` (String, Sensitive) Password for ROPC auth. May also be set via CHAMELEON_PASSWORD.
- `realm` (String) Keycloak realm name. Defaults to 'example'. May also be set via CHAMELEON_REALM.
- `ssl_verify` (Boolean) Verify TLS certificates. Defaults to true. May also be set via CHAMELEON_SSL_VERIFY.
- `timeout` (Number) HTTP request timeout in seconds. Defaults to 30.
- `token` (String, Sensitive) Static bearer token. Takes priority over other auth methods. May also be set via CHAMELEON_TOKEN.
- `username` (String, Sensitive) Username for ROPC auth. May also be set via CHAMELEON_USERNAME.
