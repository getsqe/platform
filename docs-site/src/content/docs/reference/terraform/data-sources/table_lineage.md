# chameleon_table_lineage (Data Source)

Reads the bipartite lineage graph rooted at an Iceberg table from the BFF's `/metadata/{catalog}/lineage/{namespace}/{table}` endpoint. Graph nodes are either `dataset` or `job` records; edges connect them with run-level evidence counts. An unobserved table returns an empty `nodes`/`edges` pair rather than a 404 — same shape, no error.

## Example Usage

```terraform
# Read the bipartite lineage graph rooted at an Iceberg table.
# Returns empty nodes/edges (HTTP 200) when no lineage has been observed yet.
data "chameleon_table_lineage" "orders" {
  catalog   = "main_warehouse"
  namespace = "analytics_db"
  table     = "user_summary"

  # Optional: limit walk depth (0–10) and freeze time for time-travel lineage.
  # depth = 3
  # as_of = "2026-05-01T00:00:00Z"
}

# Useful downstream: count upstream/downstream datasets touching this table.
output "upstream_dataset_count" {
  value = length([
    for n in data.chameleon_table_lineage.orders.nodes : n
    if n.kind == "dataset"
  ])
}
```

### Required

### Optional

- `as_of` (String) Optional RFC3339 timestamp for time-travel lineage. Only dataset versions whose validity range covers the timestamp participate in the walk.
- `depth` (Number) Optional walk depth (0–10). Omit for BFF default; `0` returns the root only.

- `edges` (Attributes List) Directed dataset↔job edges with run-level evidence. (see [below for nested schema](#nestedatt--edges))
- `id` (String) Composite id `<catalog>/<namespace>/<table>[@<as_of>]` for Terraform's internal addressing.

- `root_id` (String) Dataset id of the root table (`dataset:<uuid>`). Empty string when no lineage exists.
- `truncated` (Boolean) True when the walk hit the BFF's node/edge cap before exhausting reachable nodes.
- `truncation_reason` (String) Reason string when `truncated = true`. Empty otherwise.
