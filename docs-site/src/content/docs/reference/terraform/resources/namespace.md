# chameleon_namespace (Resource)

Manages an Iceberg namespace within a Chameleon catalog.

## Example Usage

```terraform
resource "chameleon_warehouse" "analytics" {
  name = "analytics"
}

# Top-level namespace.
resource "chameleon_namespace" "raw" {
  catalog = chameleon_warehouse.analytics.name
  name    = "raw"
  properties = {
    owner       = "data-engineering"
    cost_center = "DE-100"
  }
}

# Nested namespace (dot-separated path).
resource "chameleon_namespace" "raw_events" {
  catalog = chameleon_warehouse.analytics.name
  name    = "raw.events"
  properties = {
    owner = "data-engineering"
  }
}

# Workspace-scoped: pass `workspace_slug` instead of `catalog` and the provider
# resolves it to the workspace's own catalog (ws_<slug>). Pass exactly one of
# `catalog` or `workspace_slug`.
resource "chameleon_namespace" "tenant_public" {
  workspace_slug = chameleon_workspace.team_a.slug
  name           = "public"
}
```

## Schema

### Required

- `name` (String) Dot-separated namespace path, e.g. 'analytics' or 'analytics.raw'.

### Optional

- `catalog` (String) Catalog (warehouse) name. Mutually exclusive with `workspace_slug` — set exactly one.
- `properties` (Map of String) Namespace properties.
- `workspace_slug` (String) Slug of a workspace to target instead of `catalog`; resolves to the workspace's primary catalog (`ws_<slug>` with hyphens as underscores). Mutually exclusive with `catalog` — set exactly one.

### Read-Only

- `id` (String) Composite ID `<catalog>/<dot.path>`.
