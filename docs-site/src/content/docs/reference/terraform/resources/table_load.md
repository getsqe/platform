# chameleon_table_load (Resource)

Loads a CSV or parquet file into an existing Iceberg table. Set `source_uri` (file already in S3 -> /load) OR `file_path` (local file -> multipart /upload). One-shot: every input forces replacement. Loads are NOT idempotent - `append` adds rows on every replace. For local files, `file_hash` is computed so content changes trigger a reload. `overwrite` mode is non-atomic (TRUNCATE+INSERT); a failure can leave the table empty.

## Example Usage

```terraform
# Reference mode: file already in S3 -> /load
resource "chameleon_table_load" "orders_parquet" {
  catalog           = "main_warehouse"
  namespace         = "analytics_db"
  table             = "orders"
  source_uri        = "s3://my-bucket/seed/orders.parquet"
  format            = "parquet"
  mode              = "append"
  create_if_missing = true
}

# Upload mode: local CSV -> multipart /upload
resource "chameleon_table_load" "people_csv" {
  catalog      = "main_warehouse"
  namespace    = "analytics_db"
  table        = "people"
  file_path    = "${path.module}/people.csv"
  format       = "csv"
  delimiter    = ","
  header       = true
  infer_schema = true
}
```

## Schema

### Required

- `catalog` (String) Catalog (warehouse) name.
- `format` (String) csv or parquet.
- `namespace` (String) Namespace (dot-separated for multi-level).
- `table` (String) Target table name.

### Optional

- `create_if_missing` (Boolean) Create the table from inferred/provided schema if it doesn't exist.
- `delimiter` (String) CSV delimiter (single char). Only valid when format=csv.
- `file_path` (String) Local path to a file to upload. Mutually exclusive with source_uri.
- `header` (Boolean) CSV has a header row. Only valid when format=csv.
- `infer_schema` (Boolean) Infer CSV schema. Only valid when format=csv.
- `mode` (String) append or overwrite. Defaults to append.
- `source_uri` (String) s3://bucket/key of a file already in S3. Mutually exclusive with file_path.

### Read-Only

- `file_hash` (String) SHA-256 of the local file (when file_path is set); forces replacement when the file content changes.
- `id` (String) Composite id `<catalog>/<namespace>/<table>/<snapshot_id>`.
- `metadata_location` (String) Iceberg metadata JSON location after the load.
- `on_disk_format` (String) On-disk format (always parquet).
- `rows_written` (Number) Rows written by the load.
- `snapshot_id` (String) Iceberg snapshot id committed by the load.
