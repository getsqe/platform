# chameleon_workspace_admin (Resource)

Promotes a user to a workspace's admins group (ws-<slug>-admins). Requires a platform-admin identity.

## Example Usage

```terraform
resource "chameleon_workspace" "team_a" {
  slug         = "team-a"
  display_name = "Team A"
}

# Promote a user to the workspace's admins group (ws-team-a-admins). Workspace
# admins may manage their own workspace's members.
resource "chameleon_workspace_admin" "carol" {
  workspace_slug = chameleon_workspace.team_a.slug
  username       = "carol"
}
```
