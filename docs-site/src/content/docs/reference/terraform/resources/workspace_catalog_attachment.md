# chameleon_workspace_catalog_attachment (Resource)

Attaches an existing catalog to a workspace read-only (ATTACHED access). The catalog must already exist and not be the workspace's own. Requires a platform-admin identity.

## Example Usage

```terraform
resource "chameleon_workspace" "team_a" {
  slug         = "team-a"
  display_name = "Team A"
}

resource "chameleon_workspace" "shared" {
  slug         = "shared"
  display_name = "Shared datasets"
}

# Attach another workspace's catalog to team-a read-only (ATTACHED access).
# The catalog must already exist and not be team-a's own catalog. Use the
# chameleon_attachable_catalogs data source to discover valid candidates.
resource "chameleon_workspace_catalog_attachment" "shared_to_team_a" {
  workspace_slug = chameleon_workspace.team_a.slug
  catalog_name   = chameleon_workspace.shared.primary_catalog
}
```
