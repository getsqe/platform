    people running the same query can legitimately see different rows.
  </Card>
  <Card title="Open formats, no lock-in" icon="open-book">

  </Card>
  <Card title="Bring your own engine" icon="puzzle">

    policies.
  </Card>

    user's own permissions — not an admin token.
