The catalog is the map of what exists. A catalog holds namespaces, a namespace holds tables, and each table exposes the Iceberg schema and metadata that every engine on the platform reads — one definition rather than a copy per tool.

**Who does this:** analyst

## Steps

1. Open the catalog explorer

   ![Open the catalog explorer](../../../../assets/screenshots/browse-catalog-overview.png)

2. Open the catalog to see its properties and contents

   ![Open the catalog to see its properties and contents](../../../../assets/screenshots/browse-catalog-catalog.png)

3. Open a namespace to list its tables

   ![Open a namespace to list its tables](../../../../assets/screenshots/browse-catalog-namespace.png)

4. Open a table to read its Iceberg metadata

   ![Open a table to read its Iceberg metadata](../../../../assets/screenshots/browse-catalog-table.png)
