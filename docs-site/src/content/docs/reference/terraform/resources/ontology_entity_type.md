# chameleon_ontology_entity_type (Resource)

An ontology entity type (class). Lives within a `version_id` and must be created against a draft version. Names follow snake_case; attributes attach via `chameleon_ontology_attribute.entity_type_id`. Subtypes set `parent_entity_type_id` to inherit from a base class (e.g. Customer extends Person); mark base classes `is_abstract`.

## Example Usage

```terraform
resource "chameleon_ontology_entity_type" "customer" {
  version_id   = chameleon_ontology_version.v1.id
  name         = "customer"
  display_name = "Customer"
  description  = "A buyer in the e-commerce platform."
  iri          = "https://example.com/biz#Customer"
}
```

## Schema

### Required

- `display_name` (String) Human-readable label.
- `name` (String) snake_case identifier (lowercase letters/digits/underscores, must start with a letter).
- `version_id` (String) Ontology version this entity type belongs to. Must reference a draft.

### Optional

- `description` (String) Free-text description.
- `iri` (String) Optional fully-qualified IRI override. Mutually informative with `namespace_id`.
- `is_abstract` (Boolean) True for abstract base classes (no direct instances). Default false.
- `namespace_id` (String) Optional ontology namespace UUID — when set, the entity's IRI is qualified by the namespace's prefix.
- `parent_entity_type_id` (String) Parent entity type UUID for subtyping (this type inherits the parent's attributes/relations). Forces replacement when changed.
