A notebook is for the work that is not a single query: shaping a dataset, plotting it, training something and keeping a record of what you tried. The platform runs one per workspace with a kernel of its own, so the code runs next to the data rather than on a laptop with a copy of it.

**Who does this:** analyst

## Steps

1. Open Notebooks for the workspace

   ![Open Notebooks for the workspace](../../../../assets/screenshots/notebook-analysis-list.png)

2. Start one from the ML experiment template, which arrives with tracking set up

   ![Start one from the ML experiment template, which arrives with tracking set up](../../../../assets/screenshots/notebook-analysis-create.png)

3. The notebook opens with its kernel running, ready to execute

   ![The notebook opens with its kernel running, ready to execute](../../../../assets/screenshots/notebook-analysis-editor.png)
